# Handraw Gallery

编号画廊 · 261 种手绘风格缩略图导航（直链 [yang0/handraw-style](https://github.com/yang0/handraw-style)）。

GitHub Pages: https://young920.github.io/handraw-gallery/

## 用途

每次用 `wiki-to-cards` skill 做长文转小红书信息卡时：
1. 打开本画廊
2. 选一个编号（决定封面风格）
3. 把编号 + 主题告诉 AI → 调用 MiniMax image-01 生图

## 数据来源

- 编号 + 风格名：`yang0/handraw-style/styles_200_reorganized.md`
- 参考图：`raw.githubusercontent.com/yang0/handraw-style/...`

## 自动维护

由 wiki-to-cards skill 在每次接入时刷新（不主动改这里）。
